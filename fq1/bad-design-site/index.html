Anatomy of this disaster — every badge hyperlinks here (readable on purpose so it can be graded)

Reference style: early-2000s dense portals (Sina / 163 / QQ): 40+ links above the fold, 8 colours, 6 fonts, zero whitespace, marquees in 3 directions, table layout 2000px wide, popups, guestbook. Each item breaks a Nielsen heuristic on purpose. Compare with the fix in wireframe_prototype.html.

  1. No visibility of system status. “Reminder set??? maybe???” — no toast, no Autosaved, no Upcoming / Due today / Overdue / Completed. Fix: “Reminder set for 9:00 AM, one day before.” + Autosaved.
  2. No consistency — the 69 vs 67 vs 68 disease. One action, four buttons (69px / 67px / 68px / 30px), labels Add Assignment / ADD assignment!! / Process / add, statuses Due today / due_today / DUE TODAY, four “Go” buttons, four “Complete” buttons, two broken logos. Users re-learn every control. Fix: one button style, one wording: Add Assignment / Set Reminder / Mark as Completed.
  3. Cluttered nav, no real-world match. 30 links: Home / HOME / home_page / Homepage (new!), three languages mixed mid-sentence, ads disguised as nav. A third nav tier in Chinese tripled the pile. Student words (lecture, deadline, exam) buried. Fix: Today/Week/Month + course/priority/type filters.
  4. Numbers never agree (69 vs 67 vs 68). Visitor 69, planner 67% full (68% with ads), 47 vs 69 hidden tasks, midterm in 69 vs 67 hours, dates as 20.10 / Oct 20 / 10/20/2026 / 下周二. Two-pixel / two-percent mismatches destroy trust in real deadlines. Fix: single source of truth, one date format.
  5. Aesthetic / minimalist violated. Rainbow animated header, 3 marquees (left + right + up), Impact + Comic Sans + Papyrus + Courier at 9px–34px, giant table 2000px wide = horizontal scroll. Urgent deadlines drown. Fix: white + #97BCF7 + #645BE5, Today / Overdue / Upcoming hierarchy.
  6. Recognition over recall violated. “Lab B?? or Lab A?? check chat (1 of 694)”, 47 tasks in a 60px scrollbox, contradictory pills (upcoming + OVERDUE?! + maybe overdue??). Fix: dashboard shows time + room + course colour at a glance.
  7. Flexibility / findability destroyed. 13 tiny links: syllabus / syllabus (2) / FINAL / FINAL_final_REALLY, three search boxes + four Go buttons, none actually filters. Fix: Filter: all courses / Type: all that works.
  8. No user control. Delete forever — no undo lol, “are you sure? → too late, deleting anyway”, Reset right next to Add. Fix: confirm + Undo bar.
  9. No error prevention / miserable recovery. Grey boxes with no labels, black-on-black password 12345 prefilled, CAPTCHA “type 69 (or 67? image says 68)” that always fails, no Please select a deadline, no date picker, no This exam overlaps with your lecture. Fix: required title + course + valid-date picker + plain error + highlighted field.
  10. No help, lying empty states. Three reminder links, three contact emails (try all 3), “Back to top (broken, reloads ads)”, “No tasks” + 47 hidden. Fix: one reminder receipt + edit/disable + honest empty state: No tasks planned for today. Add a study task.
  11. Accessibility ignored. Yellow-on-white and gray-on-gray text, 9px body copy next to 34px headers, cursor:wait everywhere, broken alt="broken" images, audio set to autoplay+loop. Fix: contrast-checked status colours, one legible font, 12px minimum, no autoplay.
  12. Dark patterns everywhere. Right-click hijacked, onload alert, fake countdown 00:09, fake virus scan (69%… 67 threats), exit popup, mouse-following “CLICK HERE”, ads styled as deadlines, “Best viewed in IE6 · download toolbar (required)”, plus DOOM roulette — ~1 in 12 random clicks launches the game (pity at 20, the OFF switch itself is 25% DOOM), age gate (67 or 69 only), tab-title spam, midterm earthquakes, unmutable muzak, copy-paste hijack, fake RAM download. Fix: none of that — autosave indicator, honest confirmations, closable UI.
