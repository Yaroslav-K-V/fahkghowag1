# Bad Design Demo — intentionally the worst student-planner site possible

An HCI teaching demo: a deliberately cluttered, inconsistent Chinese-portal-style
planner (popups, marquees, 69 vs 67 vs 68 mismatches, dark patterns) where every
red `N` badge hyperlinks to an annotated violation (`#v1`–`#v12`). Do not copy these patterns.

- Open `index.html` in a browser.
- Every red `N` badge hyperlinks to violations `#v1`–`#v12` at the bottom.
- Covers: clutter, 69 vs 67 vs 68 inconsistency, dark patterns, no undo,
  fake urgency, autoplay, popups, low contrast, lying empty states.

Good counterpart: `wireframe_prototype.html` in the HCI3 homework folder.
